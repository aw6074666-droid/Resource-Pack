БЫСТРОЕ РАЗМЕЩЕНИЕ НА RENDER (тестовая публичная версия)

1. Создайте аккаунт на https://github.com и https://render.com.
2. На GitHub создайте новый пустой репозиторий (например, dekanat-queue).
3. Загрузите в репозиторий ВСЕ файлы и папки из этой папки проекта: app.py, database.py, service.py, requirements.txt, render.yaml, templates/, static/ и tests/.
   Не загружайте queue.db и не публикуйте пароли.
4. В Render выберите New → Blueprint, подключите GitHub и выберите репозиторий.
5. Render обнаружит render.yaml. При запросе задайте OPERATOR_PASSWORD — придумайте отдельный сложный пароль для панели оператора.
6. Дождитесь статуса Live. Render выдаст адрес вида https://dekanat-queue-korkyt-ata.onrender.com.
7. Откройте адрес с телефона через мобильный интернет. Панель оператора находится по адресу /operator и защищена логином operator и заданным паролем.

ВАЖНО: бесплатный Render подходит для демонстрации, но бесплатная файловая система временная: база SQLite может сброситься после перезапуска/повторного развёртывания, а бесплатный сервис может засыпать. Не используйте такую конфигурацию для реальной очереди без постоянной базы данных (например, PostgreSQL) и согласования с университетом. Для эксплуатации перенесите БД на PostgreSQL и настройте резервное копирование.

Локальный запуск по-прежнему возможен: py -m pip install -r requirements.txt, затем py app.py.
