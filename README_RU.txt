ЭЛЕКТРОННАЯ ОЧЕРЕДЬ В ДЕКАНАТ — запуск в Windows

1. Распакуйте архив в папку, например C:\Users\Acer\Documents\dekanat_queue_project
2. Откройте командную строку в этой папке:
   Проводник → откройте папку проекта → щёлкните адресную строку → напишите cmd → Enter.
3. Установите зависимости:
   py -m pip install -r requirements.txt
4. Запустите:
   py app.py
5. Откройте в браузере:
   http://127.0.0.1:5000
6. Панель оператора:
   http://127.0.0.1:5000/operator
Остановить сервер: Ctrl+C в командной строке.

Тесты:
   py -m pip install pytest
   py -m pytest -q

Функции:
- создание талона и последовательная нумерация;
- сохранение в SQLite (students, services, tickets);
- оценка ожидания (10 минут на одного ожидающего);
- панель оператора: вызвать / завершить;
- адаптивная верстка;
- переключатель RU / ҚАЗ (часть подписей интерфейса локализована; названия услуг отображаются на двух языках).

Примечание: это учебный прототип. Перед реальным использованием добавьте авторизацию оператора,
CSRF-защиту, настройку секретного ключа и развёртывание на production-сервере.

Оформление: использовано фото здания университета, предоставленное пользователем; цветовая схема — академический синий, светлый каменный оттенок и сдержанные золотые акценты.

Визуальная тема обновлена под Қорқыт ата атындағы Қызылорда университеті: глубокий академический синий и бирюзовые акценты. Фото предыдущего университета удалено; неофициальный логотип не используется.

В шапку сайта добавлен логотип университета имени Коркыт ата, предоставленный пользователем.
